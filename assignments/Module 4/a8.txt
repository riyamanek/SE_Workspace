2.Add media queries to your product card so that when the screen width is 600px or less, the card layout switches from horizontal (image and details side by side) to vertical (image on top, details below).

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Flipkart Product Card</title>

    <style>
        body {
            font-family: Arial, sans-serif;
            background-color: #f2f2f2;
        }

        .card {
            width: 500px;
            display: flex;
            align-items: center;
            border: 1px solid #ddd;
            margin: 100px auto;
            padding: 20px;
            border-radius: 5px;
            background-color: white;
        }

        .card img {
            width: 200px;
            height: 200px;
        }

        .name {
            font-size: 15px;

3.Set up three breakpoints (600px, 900px, 1200px) for your product card and change the card's font size and padding at each breakpoint to improve readability on different devices.<br><br><em><strong>Hint:</strong> Use @media only screen and (max-width: ...) in your CSS for each breakpoint.</em>

<head>
