1.Create an HTML file that uses semantic tags to build a simple blog post layout with <header> for the blog title, <nav> for navigation links (Home, Explore, About), <article> for the main post content, and <footer> for copyright information.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Blog</title>
</head>
<body>
    <header>
        <h1>My First Blog</h1>
        <p>
            Today, I am starting my blogging journey. Through this blog, I will
            share my thoughts, knowledge, and experiences with everyone.
        </p>
    </header>

    <nav>
        <a href="Home">Home</a>
        <a href="Explore">Explore</a>
        <a href="About">About</a>
    </nav>

    <article>
        <p>
            This is my first blog post. I am learning HTML and
            understanding how semantic tags are used to create
            a proper webpage structure.
        </p>
    </article>

    <footer>
        <h2>My Daily Blog</h2>
    </footer>
</body>
</html>

4.Given a non-semantic HTML snippet for a movie review (using only <div> and <span>), refactor it to use appropriate semantic tags like <header>, <nav>, <article>, and <footer> for improved accessibility and SEO.

<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Movie Review</title>
</head>
<body>
    <header>
        <h1>3 Idiots</h1>
    </header>
    <nav>
        <a href="Home">Home</a>

    </nav>

            The story follows three friends who face different challenges during their college journey.
