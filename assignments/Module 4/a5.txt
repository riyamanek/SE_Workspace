5.Implement a simple light/dark mode switch for a BookMyShow movie detail page using internal CSS and a toggle button. When the button is clicked, switch between light and dark color themes for the page.<br><br><em><strong>Hint:</strong> Use JavaScript to add or remove a 'dark-mode' class on the <body> and define the color themes in CSS.</em>

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        body
        {
            background-color: white;
            color: black;
            text-align: center;
        }
        .darkmode
        {
            background-color: black;
            color: white;
        }
    </style>
    
</head>
<body>
    <h1>Book MyShow</h1>
    <h2>Pritam and Pedro</h2>
    <p>Rating :- 4.5/5</p>
    <p>Comedy and Drama</p>
    <p>Hindi Movie and Time :- 2h 15min</p>
    <p>Watch Pritam and Pedro with your friends and family!</p>
    <button onclick="changemode()">Light/Dark Mode</button>

    <script>
        function changemode()
        {
            document.body.classList.toggle("darkmode");
        }
    </script>
</body>
</html>
